# Código de conducta · Code of conduct

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
([English](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)).

En resumen: trata a los demás con respeto, critica las ideas y no a las personas, y
acepta que en un proyecto pequeño las decisiones finales las toma quien lo mantiene.
No se toleran el acoso, los insultos ni la publicación de datos privados de nadie.

## Cómo informar

Escribe a **jparga@mereba.com** con el asunto «Código de conducta». Se responderá con
discreción y en un plazo razonable. Las medidas siguen las pautas de aplicación del
Contributor Covenant 2.1: corrección, advertencia, expulsión temporal o permanente.

---

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, criticize ideas rather than people; harassment, insults and publishing
anyone's private data are not tolerated. Report incidents to **jparga@mereba.com**
(subject "Code of conduct"); enforcement follows the Contributor Covenant 2.1 guidelines.
